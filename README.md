# E-Commerce Mobile Application

A mobile e-commerce application built with React Native and Expo Go. The application provides an end-to-end shopping experience, including user authentication, product catalog browsing, cart management, form validation during checkout, and order history tracking.

---

## Features

- **User Authentication:** Sign In and Sign Up screens with form validation.
- **Product Catalog:** Browse items in a structured product overview.
- **Cart Management:** Add, remove, and update quantities with real-time feedback.
- **Checkout & Validation:** Complete orders with integrated input validation and status alerts.
- **Profile & Order History:** View account details and past purchase history.
